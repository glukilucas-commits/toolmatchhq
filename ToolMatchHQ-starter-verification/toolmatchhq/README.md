# ToolMatchHQ — starter

Static starter site for the U.S. small-business software affiliate test.

## Files
- `index.html` — main site + interactive 3-question finder
- `styles.css` — responsive design
- `script.js` — finder logic + affiliate-link placeholder
- `disclosure.html` — affiliate disclosure
- `privacy.html` — starter privacy page

## First setup
1. Apply to the official HubSpot Affiliate Program.
2. After approval, copy your unique affiliate URL into `script.js` by replacing:
   `YOUR_HUBSPOT_AFFILIATE_LINK`
3. Upload the folder to a static host or web server.
4. Use the final domain as the Google Ads destination.
5. Add Google Ads conversion tracking before scaling spend.

## Important
Do not launch paid traffic until the affiliate program has accepted the account and the landing page/domain/tracking setup is live and verified.

The site is intentionally written as an independent software guide, not as an imitation of HubSpot.
